# Word Counter

A simple Python program that counts how many times each word appears in a sentence.

## Features
- Splits text into words
- Counts word frequency
- Ignores uppercase/lowercase differences
- Removes basic punctuation

## Example

Input:
Python is fun, python is great!

Output:
{'python': 2, 'is': 2, 'fun': 1, 'great': 1}
