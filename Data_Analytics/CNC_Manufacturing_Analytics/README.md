
# CNC Manufacturing Analytics
Exploring data-driven methods, statistical analysis and predictive modelling for industrial applications.

## Project Overview
CNC Manufacturing Analytics is a practical data analytics and portfolio project exploring how data-driven methods, statistical analysis and predictive modelling can be applied to industrial processes. The project uses manufacturing data as a practical context for investigating machine performance, operational patterns and predictive maintenance.

It forms part of a longer-term professional development path towards Industrial Data Science, supported by future academic studies in Applied Mathematics.

## Research Direction
The project uses the AI4I 2020 Predictive Maintenance Dataset as a starting point for investigating industrial machine failure and predictive maintenance.

The main research interests include:

- Understanding patterns in machine operating conditions.
- Exploring relationships between machine parameters and failures.
- Investigating failure types and their distributions.
- Evaluating the potential of data-driven predictive maintenance.
- Communicating industrial data insights through visualizations and dashboards.

## Objectives
- Perform data quality assessment and exploratory data analysis (EDA).
- Investigate statistical patterns in manufacturing data.
- Explore relationships between operational variables and machine failures.
- Develop practical data analysis and visualization workflows.
- Progress towards predictive modelling and model evaluation.
- Communicate findings through a Streamlit dashboard.

## Methodological Development
The project will progressively explore:

 - Data understanding and quality assessment.
 - Exploratory data analysis.
 - Descriptive statistics and statistical relationships.
 - Predictive maintenance and machine learning.
 - Model evaluation and interpretation.
 - Industrial insights and potential applications.

## Mathematical Foundations
As part of my ongoing mathematical development, I intend to progressively incorporate relevant concepts, including:

These topics will be introduced as the research questions and project requirements develop.
